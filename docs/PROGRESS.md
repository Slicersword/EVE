## Save, move or recover your progress

- Progress stays in this browser on this website. There is no account, cloud sync,
  tracking service or subscription requirement. The website never connects to your robot.
- **Export backup** downloads a JSON file containing your checkmarks, notes and completion
  dates. Export regularly, especially before changing browsers, clearing site data or moving
  to the offline copy. Keep the file with your private build records.
- On another device, open this page and choose **Import backup**. A valid backup replaces
  the current notebook after confirmation. Import does not merge two notebooks.
- **Pause tracking** locks editing and keeps your data. **Reset progress** clears this
  notebook after confirmation. Import an earlier export to recover an accidental reset.
- Private browsing or blocked browser storage can prevent persistence. The page displays
  a session-only notice; export before closing it. Local HTML files may use a different
  storage area in each browser. Moving an offline folder does not automatically move progress.
- Do not edit the notebook in multiple tabs at once; reload another tab before using it.
  The most recent save wins. Do not put passwords, access tokens or private conversations
  into notes or publish your progress backup to GitHub.

## What a checkmark means

It is your record that you performed a task. It does not measure voltage, test a sensor,
enable a motor, calibrate the robot or prove that a build is safe. Follow the hands-on
acceptance criteria in each linked instruction.

The robot's `./eve stage` records are separate and live on the Pi. Record a software
stage on the Pi only after its checks and physical test pass; mirror the result here
if useful. Website checkmarks cannot bypass commissioning gates. After replacing a part,
changing wiring, flashing different firmware or losing calibration, uncheck and repeat
the affected tasks.
